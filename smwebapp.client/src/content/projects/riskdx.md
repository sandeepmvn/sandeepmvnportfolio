## Overview

This is a complete turnkey insurance distribution platform I have led since March 2020, serving both online and agent-assisted channels. It covers product design and pricing, branded distribution, underwriting rules for immediate issue policies, and analytics for ongoing improvement. The platform has expanded over five years to include a mobile app and a standalone insurance needs analysis tool.

As Team Lead on a team of 3, I owned architecture decisions, CI/CD pipelines, and end-to-end delivery.

## Platform Capabilities

- **Quoting and Underwriting** — rules engine designed for online and agent-assisted immediate issue policies, with reinsurer support and product pricing configuration
- **Policy Delivery** — workflow-driven policy lifecycle from quote through issuance
- **Branded Distribution** — white-label platform supporting both online and agent distribution channels
- **Insurance Needs Analysis** — standalone web and mobile tool that helps customers calculate required life and critical illness insurance coverage

## Engineering Highlights

- Built backend services on ASP.NET Core Web API with Azure MySQL, deployed via Azure Web Apps and Docker
- Developed Angular web application for the distribution portal
- Extended platform to mobile (Android and iOS) using Xamarin.Forms
- Integrated Azure AI Search, Azure Text Translation, Azure Content Safety, and Azure OpenAI for content intelligence and search
- Deployed insurance analytics reports via Power BI Embedded Service
- Built and maintained CI/CD pipelines through Azure DevOps
- Managed Azure Storage Service and full production environment setup

## Power BI Embedded

Delivered insurance analytics reports deployed via Power BI Embedded Service — giving distribution teams real-time visibility into policy and underwriting performance without leaving the platform.

## Outcome

This platform has been in continuous production since 2020, expanding from a web-only platform to a multi-channel system with mobile apps, AI-powered content features, and embedded analytics. It reduces manual coordination in insurance distribution and gives teams repeatable, auditable workflows from quote to policy delivery.
